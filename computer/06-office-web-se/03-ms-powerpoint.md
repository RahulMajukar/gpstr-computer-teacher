## 1. Definition

> **Presentation software** creates a sequence of slides with text, pictures, and media for an audience.

**MS PowerPoint, Google Slides, LibreOffice Impress.** File: `.pptx`

---

## 2. Building blocks

| Item | Meaning |
|------|---------|
| Slide | One screen |
| Layout | Title, title+content, blank |
| Theme / Design | Colours and fonts |
| Transition | Effect **between** slides |
| Animation | Effect **on** an object |
| Slide show | Full screen teaching |
| Notes | Teacher script (not shown) |
| Handout | Print 2/4/6 slides per page |
| Master slide | Common header for all |

**Views:** Normal, Slide sorter, Reading, Slide show.

---

## 3. Shortcuts

F5 start show from first; Shift+F5 from current; Esc end; N / space next; P previous; B black screen; W white; Ctrl+M new slide; Ctrl+D duplicate.

---

## 4. Pedagogy: how a CST should make slides

- One idea per slide  
- Large font (24+)  
- High contrast  
- Pictures of real lab, not only clip art  
- Do not read paragraphs  
- Include a question slide
