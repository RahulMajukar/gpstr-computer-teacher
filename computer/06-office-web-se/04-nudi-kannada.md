## 1. Simple explanation

English keyboards do not type Kannada by default. **Nudi** is **Kannada software** widely used in **Karnataka government** (and many schools) to type official letters in Kannada.

Other Kannada tools: **Baraha**, **Google Input Tools**, Windows Kannada keyboard, **Lipikaar**.

For GPSTR Paper-I, **Nudi** is the name they expect.

---

## 2. Definition

> **Nudi** is a Kannada word-processing / keyboard software used to type Kannada script on a computer, commonly prescribed in Karnataka government offices and school ICT work.

---

## 3. Exam points

- Developed / popularised for **Kannada official work**  
- Works with Word and other Windows apps (depending on version)  
- Supports **Kannada fonts** and keyboard layouts  
- Teachers use it for: circulars, question papers, notices, DIKSHA-related Kannada text  
- Students of higher classes may type answers in Kannada  

**Unicode:** modern standard so Kannada text opens on any computer. Older **ASCII Kannada fonts** break if the font is missing. Prefer Unicode in new work.

---

## 4. Practical lab tip

- Install only authorised Nudi from official education / Kannada department sources  
- Keep one printed **keyboard layout chart** on the lab wall  
- Teach Class 6–8 a few letters, not the whole layout in one period
