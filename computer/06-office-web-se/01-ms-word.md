## 1. Definition

> A **word processor** is application software used to create, edit, format, save, and print text documents.

Examples: **MS Word, Google Docs, LibreOffice Writer, WordPad** (simple).

---

## 2. File types

`.docx` (modern Word), `.doc` (old), `.pdf` (print-fixed), `.rtf`, `.txt`

**Save vs Save As:** Save updates same file; Save As new name/place/type.

## 4. Shortcuts (Paper-I gold)

Ctrl+N new, O open, S save, P print, B/I/U bold italic underline, L/E/R/J align, K hyperlink, F find, H replace, A select all, Z undo, Y redo, X cut, C copy, V paste, F7 spelling, Ctrl+Enter page break.

---

## 5. Mail merge steps (5-mark)

1. Main letter in Word  
2. Data source (Excel / Access / Outlook)  
3. Insert merge fields (Name, Class)  
4. Preview  
5. Finish & Merge → print or letters  

School use: fee reminder to all parents.

## 6. MCQs

1. Ctrl+S: a) print b) save c) bold d) new  
2. Mail merge needs: a) only a printer cable b) main doc + data list c) only BIOS d) only Linux  
3. Justify means: a) only left b) both left and right edges even c) centre only d) vertical  
4. F7: a) save b) spelling c) new table d) screenshot  
5. .docx is: a) Excel b) Word c) PowerPoint d) Access  

**Answers:** 1-b, 2-b, 3-b, 4-b, 5-b

## 7. 5-mark answer

Define word processor. Five features (header, table, mail merge, spell check, save as PDF). Three shortcuts. School example: circular + student list.
