# Chapter P1-5 — General Kannada (Exam Map)

**Paper:** Paper-I Kannada (about **25 marks**) + Paper-III if medium is Kannada  
**Time:** Day 55 + daily 20 minutes  

This file is a **checklist and method**. You must practise from a **Kannada grammar school book** (8th–10th / TET Kannada guide). I will quiz you in chat when you type answers.

---

## 1. Syllabus buckets

| Area | What to drill |
|------|----------------|
| **Sandhi** | Lopa, Agama, Adesha; vowel/consonant sandhi |
| **Samasa** | Tatpurusha, Karmadharaya, Dvigu, Dvandva, Bahuvrihi, Avyayibhava |
| **Linga** | Pullinga, Streelinga, Napumsaka |
| **Vachana** | Eka, Dvi, Bahu |
| **Vibhakti pratyaya** | 1 to 7 case endings |
| **Alankara** | Upama, Rupaka, Atishayokti… |
| **Chhandassu** | Basic metre names if asked |
| **Vocabulary** | Paryaya (synonym), Viruddha (antonym) |
| **Gade / gaade** | Proverbs |
| **Comprehension** | Unseen Kannada passage |
| **Composition** | Short paragraph, letter (Paper-III) |

---

## 2. How to study (even if you are rusty)

1. Buy one **TET/GPSTR Kannada** workbook.  
2. Each day: 5 sandhi + 5 samasa + 1 passage.  
3. Maintain a **50-proverb** list.  
4. Read one Kannada news editorial on Sunday.  
5. Write 8 lines daily: ಶಾಲೆಯ ಗಣಕಯಂತ್ರ ಪ್ರಯೋಗಾಲಯ.

---

Use these in Paper-III essays if the topic is education/ICT.

---

## 4. Paper-III writing types (if Kannada medium)

- Essay (250–300 words): education, environment, Kannada language, digital India, women, health  
- Letter: to HM about lab repair; to parents about meeting  
- Expansion of proverb  
- Translation: English ↔ Kannada (short)  
- Precis / comprehension  

**Structure:** intro (2 lines) → 3 body points → conclusion. Handwriting must be readable.
