## 1. Simple explanation

A science teacher has a lab. A computer teacher **is** a lab teacher.

Children do not learn Python by hearing a speech. They learn by **seeing, doing, making mistakes, and explaining to a friend**.

Your job in GPSTR descriptive papers is to name the **method**, give a **Class 6–8 example**, and mention **evaluation**.

## 2. Methods (write 2 lines + 1 example each)

| Method | How | CS example |
|--------|-----|------------|
| **Lecture-cum-demonstration** | You show, then tell | Show IPOS with a real keyboard |
| **Laboratory** | Students do | Type a Word letter |
| **Inductive** | Examples → rule | Many even numbers → “divisible by 2” |
| **Deductive** | Rule → examples | Teach IF, then 5 problems |
| **Problem-solving** | A challenge | “Make a flowchart for attendance” |
| **Project** | Longer making | Class website / mark register |
| **Play-way / game** | Fun | Input-output sorting race |
| **Discussion / brainstorm** | Talk | “Is a phone a computer?” |
| **Collaborative / pair** | Two students, one PC | Pair programming |
| **Role play** | Act | CPU / RAM / Disk drama |
| **Computer Assisted Learning (CAL)** | Software teaches | DIKSHA, PhET-like tools |
| **Flipped** (name) | Video at home, do in class | If homework access exists |

**Best mix for CST:** short demo (10 min) + guided lab (25 min) + recap questions (5 min).

## 3. Constructivism (links to Paper-I psychology)

Children **build** knowledge. Piaget: stages. Vygotsky: **ZPD** + **scaffolding** (help just enough).

In CS: do not dump 7 OSI layers on Class 6. Start with “letter to a friend” then add layers later.

**5E model:** Engage, Explore, Explain, Elaborate, Evaluate.

## 5. Inclusive education in the computer lab

- Front seats for low vision; large fonts, high contrast  
- Screen reader (NVDA) if needed  
- Pair a shy child with a patient peer  
- Keyboard stickers for Kannada  
- Never mock typing speed  
- CWSN (Children With Special Needs) get extra time and alternate input (as per school policy)

This paragraph scores in **both** pedagogy papers.

---

## 6. Common mistakes of new CS teachers

- Only theory on board, lab locked  
- Students copy programs without dry-run  
- One child hogs the mouse  
- No closing ritual (save, shutdown, stools, log)
