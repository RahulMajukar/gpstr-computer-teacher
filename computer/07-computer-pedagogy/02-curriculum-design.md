## 1. Definitions

> **Curriculum:** the whole planned learning experience — aims, content, methods, materials, evaluation, hidden values.  
> **Syllabus:** list of topics for a course/exam.  
> **Textbook:** one tool, not the whole curriculum.

A CST who “only finishes the book” is not designing learning.

---

## 2. Principles (5-mark list)

1. **Age appropriate** — Class 3 paint; Class 8 HTML  
2. **From concrete to abstract** — mouse before binary  
3. **Spiral** — IPOS in Class 5, deeper CPU in Class 8  
4. **Balance theory and practical** (often 40:60 in ICT)  
5. **Local context** — Kannada, Nudi, Karnataka examples  
6. **Inclusion** — all learners  
7. **Safety** — cyber rules from the start  
8. **Integration** — computers in maths/science projects  
9. **Skill + values** — not only marks  
10. **Flexibility** — lab time, power cuts, few PCs  

---

## 3. Aims of school CS (write 4)

- Digital literacy for life and further study  
- Logical thinking and problem solving  
- Responsible, ethical use  
- Readiness for vocational / higher CS  

---

## 4. Suggested spiral (you can quote this in answers)

| Classes | Focus |
|---------|--------|
| 1–3 | Parts of computer, paint, care, no fear |
| 4–5 | Keyboard, Word pad, IPOS, files, internet safety story |
| 6–7 | Office, Nudi, flowchart, scratch/block coding, LAN idea |
| 8 | Python/C basics, HTML, spreadsheet formulas, cyber law one-liners |

**NEP 2020:** foundational literacy, coding/computational thinking at middle stage, experiential learning, reduced rote.  
**NCF:** competency based, 21st-century skills.

(Confirm latest SCERT Karnataka ICT syllabus when you teach for real.)

---

## 5. How to design one unit

1. Competency: “Student can create a formatted notice in Word.”  
2. Content: font, alignment, save  
3. Activities: demo → pair task → print  
4. Assessment: rubric (saved file, formatting, filename)  
5. Time: 3 periods  

**Bloom:** remember → understand → apply → analyse (Class 8). Most school CS lives in **apply**.

---

## 6. Hidden curriculum

If only boys touch the mouse, the hidden curriculum says “computers are for boys.” Rotate pairs. This is an **inclusive education** point.
