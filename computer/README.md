## What each chapter file contains

Every lesson follows the same teaching pattern:

1. **Today's goal** — what you must remember after 45–60 minutes
2. **Simple explanation** — as if a teacher is sitting with you
3. **Exam definitions** — one-line answers for MCQs
4. **Diagram / table** — easy to redraw in the exam
5. **School teaching tip** — how you would teach Classes 1–8
6. **MCQs** — with answers at the end
7. **Descriptive 5-mark outline** — ready to write in Paper-II
8. **Quick revision box** — last 2-minute recap

## Official sources to verify

Pattern and marks can change when the **official notification** is released. Always confirm on:

- [schooleducation.kar.nic.in](https://schooleducation.kar.nic.in)
- KARTET / CTET eligibility notices

The notes in this pack combine:

- GPSTR Paper-I **Computer Literacy** (about 10 marks for all teachers)
- Deeper **Computer Science subject** content (Paper-II style CST syllabus)
- Paper-I pedagogy, languages, and GK needed for the full written exam

## Daily habit (keep it small)

| Time | Task |
|------|------|
| 60–90 min | Read **one** chapter file slowly |
| 20 min | Write definitions + one diagram from memory |
| 20 min | Solve that chapter's MCQs without looking |
| 10 min | Recite the Quick Revision box aloud |

**Do not skip writing.** GPSTR Paper-II has **100 descriptive marks**. Hands must practise, not only eyes.
