## 1. Simple explanation

The **Internet** is the **network of networks** (wires, routers, ISPs).

The **WWW (World Wide Web)** is a **service** on the Internet — pages linked by HTTP, viewed in a **browser**.

Email, WhatsApp, online games also use the Internet but are not “the Web” in the strict exam sense.

---

## 2. Definitions

> **Internet:** a global system of interconnected computer networks using TCP/IP.  
> **WWW:** a collection of web pages and resources linked by hyperlinks, accessed via browsers.  
> **URL:** Uniform Resource Locator — the address of a resource.  
> **ISP:** Internet Service Provider — company that gives you connectivity (BSNL, Jio, Airtel…).  
> **Browser:** application software to request and display web pages.

---

## 3. URL anatomy

```
https://www.schooleducation.kar.nic.in/index.html
```

| Part | Meaning |
|------|---------|
| `https` | Protocol (secure HTTP) |
| `www` | Host name part |
| `schooleducation.kar.nic.in` | Domain |
| `/index.html` | Path / file |

**DNS** converts the domain to an IP.

---

## 4. Important protocols

| Protocol | Use |
|----------|-----|
| HTTP | Web pages (port 80) |
| HTTPS | Encrypted web (443) |
| FTP | File transfer (21) |
| SMTP | Send mail (25) |
| POP3 / IMAP | Receive mail |
| DNS | Name → IP (53) |

**Tim Berners-Lee** — WWW.  
**ARPANET** — ancestor of Internet.

---

## 5. Browsers

Examples: **Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, Opera.**  
Old: Internet Explorer, Netscape.

Features: address bar, bookmarks, history, tabs, downloads, extensions, private/incognito.

**Search engine** (Google, Bing) ≠ browser. You can search *inside* a browser.

**Cookies:** small files sites store about you.  
**Cache:** stored page copies for speed.  
**Home page:** first page when browser opens.
