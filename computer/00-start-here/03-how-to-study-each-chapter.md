# Lesson 0C — How to Study Each Chapter (Teacher Method)

**Time:** 15 minutes  
**Goal:** Use every `.md` file the same way so you finish 60 days without wasting time.

---

## The 4-pass method (45–70 minutes)

### Pass 1 — Listen (15 min)

Read the chapter once **without underlining**. Imagine I am teaching you. If a word is new, do not stop for Google. Finish the story first.

### Pass 2 — Mark (15 min)

Read again. In your notebook write only:

- definitions (copy exactly once)
- tables
- diagrams

Do **not** copy full paragraphs.

### Pass 3 — Close the file (15 min)

Close the computer. From memory:

1. Say the definition aloud  
2. Redraw the diagram  
3. List 5 exam points  

If you cannot, open only that heading again.

### Pass 4 — Exam (15–20 min)

Solve the chapter MCQs. Then write the 5-mark answer in **8–12 lines** with a diagram.

---

## Notebook setup (buy one 200-page book)

Divide it into 8 sections with sticky notes:

1. Fundamentals  
2. OS  
3. Programming  
4. DBMS  
5. Networks  
6. Office + Web  
7. Pedagogy + Paper-I  
8. Mistakes (very important)

In the **Mistakes** section write every MCQ you got wrong, with the correct line. Revise this section every Sunday.

| `Explain CPU like Class 6` | Super simple re-teach |

| `I am stuck on binary` | Extra drill only on that |

Do not wait to finish all files before talking. **One chapter = one conversation.**

A chapter is finished only when all four are true:

- [ ] You can teach it to a Class 7 child in 5 minutes  
- [ ] You scored at least 70% in that file's MCQs  
- [ ] You wrote the 5-mark answer without copying  
- [ ] You added wrong questions to the Mistakes section
