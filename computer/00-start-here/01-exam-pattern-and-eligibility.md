# Lesson 0A — Exam Pattern, Papers, and Eligibility

**Time:** 25 minutes  
**Goal:** Know *what* the exam tests, *how many marks*, and *what you must already have* before you start deep CS chapters.

---

## 1. What is GPSTR?

**GPSTR** = **G**raduate **P**rimary **S**chool **T**eacher **R**ecruitment (Karnataka).

For **Computer Science Teacher (CST)** you are preparing to teach **computer concepts to Classes 1–8** (upper-primary focus is usually **6–8**, but CST notes often mention 1–8).

You are not only a programmer. The government wants a teacher who can:

- explain hardware and software in simple Kannada/English
- run a school computer lab safely
- use Office tools and Nudi
- teach basic programming logic
- handle child psychology and inclusive classrooms

## 2. Typical written exam structure (verify in official 2026 notification)

Many recent GPSTR cycles use **three papers, 400 marks**:

| Paper | Type | Marks | Time | What it tests |
|-------|------|-------|------|----------------|
| **Paper-I** | MCQ (OMR) | **150** | 2 hours 30 min | GK, pedagogy, Kannada, English, health, computer literacy |
| **Paper-II** | 50 MCQ + 100 descriptive | **150** | 3 hours | **Your subject** (Computer Science for CST) |
| **Paper-III** | Descriptive | **100** | 2 hours | Language of instruction (writing, comprehension, grammar) |
| **Total** | | **400** | | |

### Paper-I mark split (commonly reported)

| Section | Marks |
|---------|-------|
| Educational Psychology + Teaching Method | 50 |
| General Kannada | 25 |
| General English | 25 |
| General Knowledge / Current Affairs | 25 |
| Health & Value / Physical Education | 15 |
| Computer Literacy | 10 |
| **Total** | **150** |

### Paper-II (subject) — why CS notes must be deep

| Part | Marks | How to prepare |
|------|-------|----------------|
| MCQ | 50 | Definitions, one-word facts, diagrams, shortcuts |
| Descriptive | 100 | 2 / 3 / 5 mark written answers, diagrams, examples |

**This is why our CS chapters teach both MCQ lines and 5-mark answer skeletons.**

## 3. Two computer syllabi you must cover

### A. Paper-I Computer Literacy (about 10 marks — easy scoring)

- What is a computer, types, hardware vs software
- Memory and devices
- OS: Windows concepts, Linux names (Ubuntu, Mint, Red Hat), Mac
- MS Office: Word, Excel, PowerPoint + shortcuts
- Internet, email, URL, ISP
- **Nudi** (Kannada typing)
- Cyber safety basics
- Sometimes: DIKSHA, ICT in Karnataka schools (Mahiti Sindhu, etc.)

### B. Paper-II / CST core Computer Science (your main scoring area)

From the syllabus you shared:

1. Computer Organization & Hardware  
2. Operating Systems (Windows + Linux)  
3. Programming & Data Structures + OOPs  
4. DBMS (ER, SQL, normalization, transactions)  
5. Computer Networks + security  
6. Web Technologies & Software Engineering  
7. Computer Pedagogy (how to teach CS, lab, curriculum)

**Study A + B together.** Chapter files already mix both.

## 4. Eligibility (typical — confirm in notification)

Keep photocopies ready. Common requirements:

| Requirement | Typical rule |
|-------------|--------------|
| Education | Graduation in the relevant subject + **B.Ed** (or as notified for CST) |
| Marks | Often **50%** (relaxation for reserved categories, often **45%**) |
| TET | **KARTET** or **CTET** (Paper-II for classes 6–8 is commonly required) |
| Age | Often **21 to 42** (General); relaxations for reserved categories |
| Language | Kannada knowledge / KEA Kannada test if you did not study Kannada |
| Domicile | Karnataka residence rules are usually strict |

**Do this this week:** download the official PDF when released and tick each point. Do not depend only on coaching WhatsApp messages.

## 5. Merit idea (reported for 2026 — confirm officially)

Some 2026 explainers mention a **competitive-exam heavy** formula, for example:

- Written exam (CET/GPSTR papers): **70%**
- TET score: **20%**
- Academics (degree + B.Ed): **10%**

Meaning: **your written papers matter most.** Daily writing practice is not optional.

## 6. OMR rules you must memorise (Paper-I and Paper-II MCQ)

1. Use **blue/black ballpoint** only (follow the admit card).
2. Darken the full circle. No tick, no cross, no half fill.
3. **No whitener** on OMR.
4. One question = one bubble. Two bubbles = zero.
5. Write roll number **and** bubble it. Mismatch can cancel the sheet.
6. Rough work only on the question booklet, never on OMR.

---

## 7. How Paper-II descriptive answers are checked

Examiners look for:

1. **Definition** in the first 2 lines  
2. **Points** (numbered), not a long story  
3. **One diagram** if the topic has one (CPU, OSI, ER, stack)  
4. **One school example** (you are a teacher)  
5. **Conclusion** of 1 line  

We give a ready skeleton in every chapter. Copy that style in the exam.
