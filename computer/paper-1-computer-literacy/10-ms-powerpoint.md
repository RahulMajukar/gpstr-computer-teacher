## 1. Definition

> **MS PowerPoint** is presentation software used to create a sequence of **slides** with text, pictures, charts, and media.

File: `.pptx` (new), `.ppt` (old).

**Applications:** class lessons, school functions, project viva, office meetings, awareness programmes (health, cyber safety).

---

## 2. Important words

| Word | Meaning |
|------|---------|
| **Slide** | One screen |
| **Slide design / Theme** | Ready colours, fonts, background |
| **Layout** | Title slide, title + content, blank, two content |
| **Placeholder** | Box that says “Click to add title” |
| **Transition** | Effect **between** two slides |
| **Animation** | Effect **on** one object (text flies in) |
| **Slide show** | Full-screen teaching mode |
| **Notes** | Teacher script under the slide |
| **Handout** | Many slides on one printed page |
| **Slide master** | Common header/logo for all slides |
| **Slide sorter** | See all slides as thumbnails; reorder |

---

## 3. How to run a show

| Key | Action |
|-----|--------|
| **F5** | Start from **first** slide |
| **Shift+F5** | Start from **current** slide |
| **Esc** | End show |
| **N** / Space / click | Next |
| **P** / Backspace | Previous |
| **B** | Black screen |
| **W** | White screen |
| Ctrl+M | New slide (edit mode) |

---

## 4. Design and animation (exam difference)

- **Design** = look of the whole slide (theme).  
- **Transition** = how you **go to the next slide**.  
- **Animation** = how a **title or picture** appears.

Do not mix these three in MCQs.

---

## 5. Good teaching slides (you are a CST)

- One idea per slide  
- Large font  
- Pictures of real lab  
- A question slide at the end

## 6. MCQs

a) Word  b) Excel  c) PowerPoint  d) Paint

**3.** Animation is:  
a) Between slides only  b) Effect on an object  c) A formula  d) An OS  

**4.** Transition is:  
a) Between slides  b) A cell formula  c) A virus  d) Recycle Bin  

**5.** Slide sorter helps you:  
a) Compile C  b) Reorder slides  c) Format disk  d) Set date only  

**6.** PowerPoint is mainly:  
a) Presentation software  b) A compiler  c) A browser only  d) A scanner  

### Answers

1-c, 2-b, 3-b, 4-a, 5-b, 6-a
