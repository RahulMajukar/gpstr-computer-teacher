## 1. Brief history of the Internet

| Time / name | Point |
|-------------|--------|
| **1960s** | US defence project **ARPANET** — first packet network |
| **TCP/IP** | Common language of the Internet (Vint Cerf, Bob Kahn — sometimes asked) |
| **1980s–90s** | Networks join; Internet grows to universities then public |
| **1991** | **Tim Berners-Lee** — **World Wide Web** (WWW) at CERN |
| **Browser** | Mosaic, then Netscape, then IE, now Chrome / Edge / Firefox |
| **Today** | Fibre, 4G/5G, Wi-Fi; education, UPI, email, video |

**Internet** = the **network of networks** using TCP/IP.  
**WWW** = a **service** on the Internet (web pages in a browser).  
Email and chatting also use the Internet but are not the same as “the Web”.

## 2. Official terms (one line each)

| Term | Meaning |
|------|---------|
| **Internet** | Worldwide connection of computer networks |
| **WWW** | World Wide Web — linked pages viewed in a browser |
| **Web page** | One document on the web (text, pictures, links) |
| **Website** | A group of related web pages (school site) |
| **Web link / hyperlink** | Clickable text or picture that opens another page |
| **URL** | Uniform Resource Locator — address of a page |
| **ISP** | Internet Service Provider — company that gives the connection (Jio, Airtel, BSNL, ACT…) |
| **Browser** | Software to open pages (Chrome, Firefox, Edge, Safari) |
| **Search engine** | Site that **finds** pages (Google, Bing, Yahoo) — **not** the same as a browser |
| **LAN** | Local Area Network — room, lab, campus |
| **WAN** | Wide Area Network — city/country/world; the Internet is the biggest WAN |
| **Home page** | First page of a site, or the page your browser opens first |
| **Download** | Copy from internet **to** your PC |
| **Upload** | Send from your PC **to** internet |
| **HTTP / HTTPS** | Web protocol; **S** = secure (padlock) |
| **DNS** | Converts name → IP address |

## 3. URL example

```
https://www.schooleducation.kar.nic.in/index.html
```

| Part | Meaning |
|------|---------|
| `https://` | Protocol (secure) |
| `www` | Host part (often) |
| `schooleducation.kar.nic.in` | Domain |
| `/index.html` | File / path |

## 4. LAN vs WAN (syllabus pair)

| LAN | WAN |
|-----|-----|
| Small area | Large area |
| School lab | Internet, railway booking |
| Often cables + switch | Routers, ISP, leased lines |
| Faster, cheaper inside | Slower / paid connection |

**MAN** = city (sometimes asked even if not in this list).  
**PAN** = Bluetooth, few metres.

## 5. Search engines vs browser

You **open Chrome** (browser) and **type in Google** (search engine).  
You can also type a full URL in the **address bar** and skip search.

**Good search:** use clear words — `Karnataka GPSTR computer literacy syllabus`.
