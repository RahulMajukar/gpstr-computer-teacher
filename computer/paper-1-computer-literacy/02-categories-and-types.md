# Literacy 2 — Broad Categories and Types of Computers

**Syllabus line:** Broad categories of computers / Types of computers  
**Time:** 45 minutes  

---

## Today's goal

Know **three ways** papers classify computers: size, purpose, and working principle.

---

## 1. By size / power (broad categories)

| Type | Who uses it | Example / exam point |
|------|-------------|----------------------|
| **Supercomputer** | Scientists, weather, defence | Fastest; India’s **PARAM** (C-DAC) |
| **Mainframe** | Banks, railways, large offices | Many users at once |
| **Minicomputer** | Medium organisation | Between mainframe and PC (older term) |
| **Microcomputer / PC** | Home, school, office | Desktop, laptop — most common |
| **Workstation** | Design / CAD | Powerful PC |
| **Server** | Serves many clients | School or office server |

### Portable / small (also asked)

| Type | Note |
|------|------|
| Laptop / notebook | Portable PC |
| Tablet | Touch screen |
| Smartphone | Computer + phone |
| PDA | Old handheld (history MCQ) |
| Embedded | Hidden in ATM, washing machine, car |

---

## 2. By purpose

| Type | Meaning | Example |
|------|---------|---------|
| **General purpose** | Many different jobs | School computer |
| **Special purpose** | One fixed job | ATM computer, traffic signal box |

---

## 3. By working principle

| Type | Works on | Today |
|------|----------|-------|
| **Analog** | Continuous values (speed, temperature) | Old meters |
| **Digital** | 0 and 1 | School PCs, phones |
| **Hybrid** | Both | Some hospital machines |

**Must remember:** modern computers are **digital**.

---

## 4. Generations (often mixed into “types / language”)

| Gen | Technology | Example |
|-----|------------|---------|
| 1st | Vacuum tubes | ENIAC, UNIVAC |
| 2nd | Transistors | IBM 1401 |
| 3rd | ICs | IBM 360 |
| 4th | Microprocessor | PCs (Intel 4004 onwards) |
| 5th | ULSI / AI | Supercomputers, AI systems |

---

## 5. MCQs

**1.** PARAM is a:  
a) Mini  b) Micro  c) Supercomputer  d) Analog only  

**2.** A school desktop is a:  
a) Supercomputer  b) Microcomputer  c) Mainframe  d) Hybrid only  

**3.** ATM machine computer is mainly:  
a) General purpose  b) Special purpose  c) Supercomputer  d) Mainframe  

**4.** Digital computers use:  
a) Only steam  b) 0 and 1  c) Only pictures  d) Only sound  

**5.** Fourth generation uses:  
a) Vacuum tubes  b) Transistors  c) Microprocessor  d) Only gears  

**6.** Many bank terminals connect to a:  
a) Plotter  b) Mainframe / server  c) Paint file  d) Screensaver  

### Answers

1-c, 2-b, 3-b, 4-b, 5-c, 6-b

---

## Quick revision

Super > Mainframe > Mini > Micro. General vs special. Analog / digital / hybrid. 4th gen = microprocessor. PARAM = C-DAC.
