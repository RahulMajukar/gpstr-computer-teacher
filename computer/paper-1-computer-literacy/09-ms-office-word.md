## 1. Types of application software

| Type | Job | Example |
|------|-----|---------|
| Word processor | Letters, notes | **MS Word** |
| Spreadsheet | Numbers, charts | **MS Excel** |
| Presentation | Slides | **MS PowerPoint** |
| Database | Tables, records | MS Access |
| Graphics / paint | Drawing | **MS Paint**, Photoshop |
| Browser | Internet | Chrome, Edge |
| Email | Mail | Outlook, Gmail |
| Accounting | Accounts | Tally |
| Education | Learning | DIKSHA apps, Scratch |
| DTP | Magazines | Publisher, PageMaker |
| Communication | Chat / meet | Teams, Zoom |

**MS Office** is a **package** (suite): Word + Excel + PowerPoint + Outlook + Access (edition-wise) + OneNote, etc. Brand: **Microsoft**.

Other suites: **LibreOffice**, Google Docs/Sheets/Slides.

## 2. MS Word — what it is

> **MS Word** is a word processor used to create, edit, format, save, and print documents.

Files: `.docx` (new), `.doc` (old). You can **Save As** PDF.

## 3. Screen parts (syllabus words)

| Part | Meaning |
|------|---------|
| **Title bar** | File name + Word |

## 4. Document and page layout options

| Option | Use |
|--------|-----|
| Margins | Space around the page |
| Orientation | **Portrait** (tall) or **Landscape** (wide) |
| Size | A4 (common in India), Letter |
| Columns | Newspaper look |
| Page colour / borders | Design |
| Header / footer | School name, page number |
| Line spacing | 1.0, 1.5, 2.0 |
| Alignment | Left, centre, right, **justify** |
| Indent | First-line / paragraph indent |
| Page break | Ctrl+Enter — new page |
| Zoom | Bigger/smaller view (does not change print size the same way as font) |

**Home tab:** font name, size, **B I U**, text colour, bullets, numbering, alignment.

**Insert:** table, picture, header, page number, text box, WordArt, shapes, hyperlink.

## 5. Editing actions the syllabus lists

| Action | Meaning | Shortcut |
|--------|---------|----------|
| **Cut** | Remove and keep in clipboard | Ctrl+X |
| **Copy** | Keep original; copy to clipboard | Ctrl+C |
| **Paste** | Put clipboard content | Ctrl+V |
| **Undo** | Reverse last action | Ctrl+Z |
| **Redo** | Undo the undo | Ctrl+Y |
| **Save** | Write to the same file | Ctrl+S |
| **Save As** | New name / folder / type | F12 (often) |
| **Select all** | Whole document | Ctrl+A |
| **Find** | Search a word | Ctrl+F |
| **Replace** | Find and change | Ctrl+H |
| **Print** | Paper or PDF | Ctrl+P |
| **New** | Blank document | Ctrl+N |
| **Open** | Existing file | Ctrl+O |
| **Bold / Italic / Underline** | | Ctrl+B / I / U |

**Clipboard** = temporary holding place for cut/copy.

**Sorting** in Word: select a list or table column → Home → Sort (A to Z / Z to A). Used for names in a table.

## 6. More Word facts for MCQ

- Spell check: **F7** / Review → Spelling  
- Thesaurus: synonyms  
- Mail merge: one letter × many names from Excel  
- Template: ready letterhead

## 7. MCQs

**1.** MS Word is:  
a) OS  b) Word processor  c) A browser  d) A CPU  

**2.** Ctrl+C then Ctrl+V:  
a) Cut only  b) Copy and paste  c) Save  d) Print  

**3.** Ctrl+Z is:  
a) Redo  b) Undo  c) New  d) Bold  

**4.** Portrait means:  
a) Page is wide  b) Page is tall  c) A virus  d) A chart  

**5.** Justify alignment:  
a) Only left  b) Both left and right edges even  c) Only centre  d) Vertical only  

**6.** .docx is:  
a) Excel  b) Word  c) PowerPoint  d) Paint  

**7.** Sorting in Word is used to:  
a) Cool the CPU  b) Arrange A–Z or by number  c) Set IP  d) Lock Windows  

**8.** Save As is used when you want:  
a) Only undo  b) A new name or type (e.g. PDF)  c) Only wallpaper  d) Only sound  

### Answers

1-b, 2-b, 3-b, 4-b, 5-b, 6-b, 7-b, 8-b
