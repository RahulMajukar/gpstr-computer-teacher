# Literacy 1 — What is a Computer?

**Syllabus line:** What is a computer?  
**Paper:** Paper-I Computer Literacy  
**Time:** 40 minutes  

---

## Today's goal

1. Say the exam definition without looking  
2. Explain IPOS  
3. Name characteristics and limitations  
4. Score a 1-mark MCQ on GIGO / data / information  

---

## 1. Simple explanation

A **computer** is an electronic machine. You give it **data**, it follows a **program**, and it gives a useful **result**.

School picture: the clerk reads marks (input), adds them (process), writes the total (output), and keeps the register (storage).

---

## 2. Exam definition (memorise)

> A **computer** is an electronic device that accepts data as **input**, **processes** it according to instructions, gives **output**, and can **store** data for later use.

**IPOS cycle:** Input → Process → Output → Storage

| Stage | Meaning | Example |
|-------|---------|---------|
| Input | Enter data | Type a name |
| Process | CPU works | Add two numbers |
| Output | Show result | Print / display |
| Storage | Keep data | Save on hard disk |

**Data** = raw facts (45, 67)  
**Information** = processed, useful result (average = 56)

---

## 3. Characteristics

| Point | One line |
|-------|----------|
| Speed | Very fast |
| Accuracy | Correct if input is correct |
| Diligence | Never tired |
| Versatility | Many jobs on one machine |
| Storage | Large data in small space |
| Automation | Runs a program by itself |

**GIGO** = Garbage In, Garbage Out. Wrong input → wrong output.

**Limitations:** no feelings, no own intelligence, needs electricity and a correct program.

## 5. MCQs

**1.** Computer is an:  
a) Mechanical toy only  b) Electronic device  c) Only a printer  d) Only a phone wire  

**2.** IPOS last letter stands for:  
a) Speed  b) Storage  c) Software  d) Screen  

**3.** GIGO means:  
a) Good In Good Out  b) Garbage In Garbage Out  c) Great Internet Go Online  d) None  

**4.** Raw facts are called:  
a) Information  b) Data  c) Software  d) Output only  

**5.** Father of the computer:  
a) Bill Gates  b) Charles Babbage  c) Linus Torvalds  d) Tim Berners-Lee  

### Answers

1-b, 2-b, 3-b, 4-b, 5-b
