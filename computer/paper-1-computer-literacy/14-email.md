# Literacy 14 — Electronic Mail (E-mail)

**Syllabus line:** Creating e-mail IDs – sending mail – attaching files – composing – downloading – viewing mails – creating folders  
**Time:** 45 minutes  

---

## Today's goal

Walk through email **exactly as the syllabus lists it** — as if you are teaching a new teacher in the staff room.

---

## 1. What is e-mail?

> **E-mail (electronic mail)** is a method of sending messages and files from one computer user to another over the Internet.

Address form:

```
username@domain
teacher.ravi@gmail.com
```

`@` is read **at**. The part after `@` is the **mail server / provider** (gmail.com, yahoo.com, rediffmail.com, karnataka.gov.in).

**Webmail:** open Gmail in a **browser**.  
**Mail software:** Microsoft **Outlook**, Thunderbird.

---

## 2. Creating an e-mail ID

Typical steps (Gmail-style; idea is the same everywhere):

1. Open the provider site (e.g. gmail.com)  
2. Click **Create account**  
3. Enter name, choose a **unique username**  
4. Set a **strong password**  
5. Give a mobile number; verify **OTP**  
6. Accept terms  
7. You get `yoursomething@gmail.com`

**School tip:** do not use a child’s full date of birth as the only password. Teachers should keep a school official ID for HM letters.

---

## 3. The mail window (compose)

| Field | Meaning |
|-------|---------|
| **To** | Main receiver |
| **Cc** | Carbon copy — others **see** who was copied |
| **Bcc** | Blind carbon copy — others **do not see** these names |
| **Subject** | Short title (exam favourite: always write a subject) |
| **Body** | The message |
| **Attach** | Paper-clip icon — add files |
| **Send** | Deliver the mail |
| **Draft** | Save without sending |

**Composing** = writing To, Subject, and Body, then Send.

---

## 4. Attaching files

1. Click the **paper clip / Attach**  
2. Choose a file (Word, PDF, photo, Excel)  
3. Wait until it uploads  
4. Send  

**Limits:** Gmail is often around **25 MB** per mail (exam: “attachments have a size limit”).  
Very large files: use Drive link, not attach.

**Danger:** do not open unknown attachments (virus). Scan school pendrive files first.

---

## 5. Sending, viewing, downloading

| Action | Meaning |
|--------|---------|
| **Send** | Mail goes to the receiver’s inbox |
| **View / Inbox** | Open received mails; unread often **bold** |
| **Download attachment** | Save the file from the mail **to your PC** |
| **Reply** | Answer the sender |
| **Reply all** | Answer everyone in To + Cc |
| **Forward** | Send the same mail to someone new |
| **Refresh** | Check for new mail |

---

## 6. Folders (syllabus: creating folders)

Default folders / labels:

| Folder | What is there |
|--------|----------------|
| **Inbox** | Incoming mail |
| **Sent** | Mail you sent |
| **Drafts** | Not yet sent |
| **Spam / Junk** | Suspected unwanted mail |
| **Trash / Bin** | Deleted (emptied later) |
| **Starred / Important** | You marked them |

**Create a folder / label** (example: `HM-letters`, `DIKSHA`, `GPSTR`):

- Gmail: Labels → Create new  
- Outlook: Folder → New folder  

Then **move** or **filter** mails into that folder so the inbox stays clean.

---

## 7. Protocols (one-line MCQ)

| Protocol | Job |
|----------|-----|
| **SMTP** | **Send** mail |
| **POP3** | Receive and often **download** to one PC |
| **IMAP** | Receive; mail stays on server (phone + PC) |

Ports sometimes asked: SMTP 25, POP3 110, IMAP 143 (or secure variants).

---

## 8. Netiquette for teachers

- Clear subject: `Lab UPS repair – GHPS Hosakote`  
- Polite greeting and name  
- Official language  
- Do not send chain jokes from the school ID  
- Check To before Send
