## 1. Simple explanation

**Memory** is where the computer keeps data and instructions.

- **Primary memory** = the table you are working on now (RAM, ROM, cache)  
- **Secondary memory** = the almirah (HDD, SSD, pen drive)  

When you switch off, **RAM is wiped**. The file on the disk stays.

---

## 2. Primary memory

### RAM — Random Access Memory

- Temporary / **volatile** (needs power)  
- Read and write  
- Holds Windows and open programs  
- More RAM → computer feels faster  
- Types you may see: DRAM (main), SRAM (cache), DDR3/DDR4 sticks  

### ROM — Read Only Memory

- Permanent / **non-volatile**  
- Stores start-up program (**BIOS / UEFI**)  
- Types: PROM, EPROM (UV erase), EEPROM, **Flash**  

### Cache

Very fast memory near the CPU (usually SRAM). L1, L2, L3.

### Registers

Tiny, fastest memory **inside** the CPU.

---

## 3. Secondary memory devices

| Device | Type | Exam point |
|--------|------|------------|
| **HDD** | Magnetic disk | Cheap, moving parts, slower |
| **SSD** | Flash chips | Fast, no spinning |
| **Pen drive / USB flash** | Flash | Portable |
| **Memory card** | SD / microSD | Phones, cameras |
| **CD** | Optical | About **700 MB** |
| **DVD** | Optical | About **4.7 GB** (single layer) |
| **Blu-ray** | Optical | About **25 GB** (single layer) |
| **Floppy** | Magnetic | **1.44 MB** — old MCQ |

**Units:** 1024 B = 1 KB … 1024 GB = 1 TB.

---

## 4. RAM vs ROM (write this table)

| Point | RAM | ROM |
|-------|-----|-----|
| Full form | Random Access Memory | Read Only Memory |
| Volatile | Yes | No |
| Use | Running programs | Boot / firmware |
| Read/Write | Both | Mostly read |

---

## 5. Other words

- **Volatile** = forgotten when power off  
- **Online storage / cloud** = Google Drive, etc. (secondary, remote)  
- **Virtual memory** = disk used as extra RAM (slower)
