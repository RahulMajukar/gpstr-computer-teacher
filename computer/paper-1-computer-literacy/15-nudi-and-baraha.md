## 1. Brief information of Nudi software

> **Nudi** is Kannada typing and font software used to type the **Kannada script** on a computer. The **Government of Karnataka** supported it. It was published / developed with **Kannada Ganaka Parishat (KGP)**.

**GO often cited in notes:** ITD 234, 27 December 2001 (Bangalore) — government funded Nudi.

**Why schools and offices use it**

- Official circulars, notices, and files in Kannada  
- Question papers and school magazines  
- Works with **MS Word** and many Windows programs  
- Free / government-distributed (install from authorised education / Kannada department sources)

**Name:** “Nudi” relates to speech / Kannada usage.  
**Keyboard idea:** you type on a normal English keyboard; Nudi maps keys to Kannada letters (KaGaPa / Nudi layout). Keep a **layout chart** on the lab wall.

**Versions (MCQ flavour)**

| Version idea | Encoding |
|--------------|----------|
| Older Nudi (up to about 5.x) | Mainly **font / ASCII (monolingual)** encoding |
| Nudi **6.0 and later** | **Unicode** based |

You do not need every version number. Remember: **old Nudi = special fonts; new Nudi = Unicode**.

## 2. Options in Nudi (what the paper means by “options”)

When Nudi is running, a small icon often sits near the **clock (system tray)**. From Nudi menus / options you typically choose:

| Option | Meaning |
|--------|---------|
| **Language** | Kannada or English |
| **Keyboard layout** | Nudi / KaGaPa layout (sometimes Inscript / phonetic in later tools) |
| **Font** | Which Kannada face to use (Nudi, Unicode font, etc.) |
| **Single language** | Stay in one script (see below) |
| **Unicode / ANSI** | How letters are stored |
| **On / Off** | Start or stop Kannada typing |

**Where you type:** Word, Notepad, some DTP software (PageMaker in older labs), school forms.

If Kannada boxes look like **garbage (?????? or English junk)**, the **wrong font** is selected, or the file is old Nudi opened without Nudi fonts.

## 3. Unicode font

> **Unicode** is an international character standard. Each Kannada letter has a unique code. The same file can open on **another computer, phone, or website** if a Kannada Unicode font is installed (or built into the OS).

| Unicode Kannada | Old Nudi / ASCII font encoding |
|-----------------|--------------------------------|
| Works in browser, email, WhatsApp, DIKSHA | Often **only** looks correct with that Nudi font |
| Find/Replace and file names work better | Find box may show junk |
| Preferred for **new** school work | Still seen in **old** government / DTP files |

**Exam line:** For new documents, prefer **Unicode Kannada**. Use old Nudi fonts only when you must open a legacy file.

Windows also has a built-in **Kannada keyboard**. Nudi is still the name **this syllabus** prints.

## 4. Scroll Lock options (very common MCQ)

On many Nudi / Kannada keyboard setups:

> **Scroll Lock ON** → type **Kannada**  
> **Scroll Lock OFF** → type **English**

(Some versions also use **F12** or another toggle. If two options appear, **Scroll Lock** is the one this syllabus names.)

**Scroll Lock** is a key on the keyboard (often near Print Screen). A light may turn on.

**School demo:** type a sentence, press Scroll Lock, type again — script changes. This is a full Class 6–8 practical.

## 5. Single language

**Single language** means the keyboard stays in **one** script so you do not mix by accident.

| Mode | Use |
|------|-----|
| **Single language — Kannada** | Whole notice in Kannada |
| **Single language — English** | Only English |
| **Bilingual / toggle** | Scroll Lock (or F12) to jump between English and Kannada in one file (e.g. `Class 7A` + `ಗಣಿತ`) |

Official letters are often **Kannada single language**. Science worksheets may be bilingual.

## 6. Standard fonts and TrueType fonts (TTF)

The syllabus asks you to **name the difference**, not design a font.

| Point | Standard / bitmap / older screen fonts | **TrueType fonts (TTF)** |
|-------|----------------------------------------|---------------------------|
| How they draw | Fixed dots (bitmap) — look blocky when enlarged | Mathematical outlines — stay **smooth** when you change size |
| Print quality | Poor if you make letters very big | Good on screen and printer |
| Extension | Older system fonts | `.ttf` |
| Use in Nudi | Early Kannada faces | Modern Nudi / Unicode Kannada faces |

**OpenType (OTF)** is a later family (sometimes asked as “better than TTF”). For this paper, remember:

> **TrueType** = scalable, sharp Kannada at any size.  
> **Standard / non-TTF** = may look broken when you zoom or print a poster.

**Always pick a Kannada font** after typing. If you type in Nudi but the Word font is **Times New Roman** only, letters can look wrong.

## 7. Other Kannada software — Baraha

> **Baraha** is another popular software to type **Kannada** (and many other Indian languages) on Windows.

| Point | Baraha | Nudi |
|-------|--------|------|
| Main use | Kannada + many Indian languages | Mainly **Kannada** (Karnataka official) |
| Typing style | Often **phonetic** (type `kannada` → ಕನ್ನಡ) plus other layouts | Nudi / KaGaPa layout (learn the chart) |
| Maker | Private product (Baraha.com); used widely since late 1990s | Govt / **Kannada Ganaka Parishat** |
| Toggle (typical) | **F11 / F12** English ↔ Indian language | **Scroll Lock** (syllabus) |
| Unicode | Yes in modern Baraha tools (BarahaPad, BarahaIME) | Yes in Nudi 6+ |

**Other names (extra, not in this unit but useful):** Google Input Tools, Windows Kannada, Lipikaar, BarahaIME.

**For the exam, if they ask “other Kannada software” the printed answer is **Baraha**.**

## 8. School / lab use (CST)

- Install **authorised Nudi** on teacher and student PCs  
- Unicode for anything that will go on email or DIKSHA  
- Printed Nudi key chart  
- Teach Scroll Lock before a Kannada typing period  
- Do not mix old Nudi font files with Unicode in one circular

## 10. Descriptive 5-mark outline

**Question:** What is Nudi? Explain Unicode, Scroll Lock, and Baraha.

1. Nudi = Kannada software; KGP / Karnataka government.  
2. Used in Word for official Kannada.  
3. Unicode = same text on any modern computer; old fonts need Nudi faces.  
4. Scroll Lock toggles Kannada / English.  
5. TTF = scalable sharp fonts.  
6. Baraha = other Kannada software; often phonetic; F11/F12.
