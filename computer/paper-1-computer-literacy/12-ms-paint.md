## 1. What is MS Paint?

> **MS Paint** (Paint) is a simple **graphics / drawing** application that comes with **Microsoft Windows**. You can draw, colour, and do basic photo edits.

It is **application software**. File types: **`.png`**, **`.jpg` / `.jpeg`**, **`.bmp`**, **`.gif`**. Older default was often **BMP**.

Open: Start → search **Paint**.  
In Windows 11 you may also see **Paint** with a few extra tools; the exam still uses the classic tool names.

---

## 2. Applications (why we use it)

- Draw diagrams for Class 1–5 (house, flag, traffic light)  
- Label a computer (keyboard, monitor)  
- School posters and certificates (simple)  
- Crop or mark a screenshot  
- Colour a map outline  
- Make a simple logo or house-icon for a project  
- Edit a photo lightly (resize, flip)

It is **not** Photoshop. No layers like professional tools (classic Paint).

---

## 3. Different tools (memorise this table)

| Tool | What it does |
|------|----------------|
| **Pencil** | Freehand thin line |
| **Brush / Brushes** | Thicker artistic stroke |
| **Fill / Paint bucket / Colour 2 fill** | Fill a closed shape with colour |
| **Eraser** | Rub out (uses background colour) |
| **Colour picker / Pick color / Eyedropper** | Click a colour on the picture to reuse it |
| **Magnifier / Zoom** | Enlarge the view |
| **Text (A)** | Type words on the drawing |
| **Line** | Straight line (hold Shift for horizontal/vertical/45°) |
| **Curve** | Bent line |
| **Rectangle** | Box |
| **Oval / Ellipse** | Circle or oval (Shift for circle) |
| **Rounded rectangle** | Box with round corners |
| **Polygon** | Many-sided shape; click points |
| **Triangle / other shapes** | Ready shapes (newer Paint) |
| **Select (rectangle / free-form)** | Select a part to cut, copy, move |
| **Crop** | Keep only the selected part |
| **Rotate / Flip** | Turn or mirror |
| **Resize / Skew** | Make bigger/smaller; slant |
| **Colour boxes (palette)** | Colour 1 (left-click), Colour 2 (right-click) |

**Clipboard in Paint:** Ctrl+C / X / V work after you **Select**.

**Undo:** Ctrl+Z. **Save:** Ctrl+S.

---

## 4. Colour 1 and Colour 2

- **Left-click** draws with **Colour 1** (foreground).  
- **Right-click** often draws/fills with **Colour 2** (background).  
- Eraser paints with the background colour.

---

## 5. Menu / ribbon ideas

**File:** New, Open, Save, Save as, Print, From scanner (older).  
**Home:** tools, shapes, colours, clipboard.  
**View:** zoom, gridlines, status bar, full screen (in some versions).

**Canvas size:** Resize the drawing area if the picture is too small for a poster.

---

## 6. School teaching tip

Class 3–5: “Draw the national flag with Rectangle + Fill.”  
Class 6: screenshot of Desktop → Paint → crop → save as PNG for a note.

Do not spend a whole period on 3D in new Paint. Exam asks **classic tools**.
