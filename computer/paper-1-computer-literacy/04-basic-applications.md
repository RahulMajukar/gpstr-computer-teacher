**Time:** 30 minutes

## Today's goal

List **where** computers are used. Paper-I loves everyday examples.

---

## 1. Application areas

| Field | What computers do |
|-------|-------------------|
| **Education** | Smart class, DIKSHA, online tests, school records |
| **Office** | Letters, salary, files, presentations |
| **Banking** | ATM, core banking, UPI backends |
| **Hospitals** | Reports, billing, records |
| **Railways / airports** | Reservation, display boards |
| **Science** | Weather, research, PARAM-class work |
| **Business** | Billing, stock, Tally |
| **Home** | Bills, learning, entertainment |
| **Government** | Aadhaar centres, e-office, land records |
| **Media** | News, design, video |
| **Defence** | Communication, simulation |

## 3. MCQs

**1.** ATM is an application of computers in:  
a) Only painting  b) Banking  c) Only cooking  d) Only sports rules  

**2.** DIKSHA is mainly used in:  
a) Mining  b) Education  c) Only banking cheques  d) Only weather  

**3.** Preparing a school circular is done mainly in:  
a) A word processor  b) A compiler only  c) BIOS only  d) A hub  

### Answers

1-b, 2-b, 3-a
