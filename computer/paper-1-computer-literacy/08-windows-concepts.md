## Today's goal

Name every object on a Windows screen and what it does. That is what this syllabus wants.

## 1. What is a “window”?

In **Microsoft Windows**, a **window** is a rectangular area on the screen for one program (Word, Chrome, Folder).

You can **minimise**, **maximise / restore**, and **close** it (buttons at the top-right).

---

## 2. Different icons on the computer screen

An **icon** is a small picture that stands for a program, file, folder, or disk.

| Common desktop icon | Meaning |
|---------------------|---------|
| **This PC / My Computer** | Drives C:, D:, devices |
| **Recycle Bin** | Deleted files (not gone until emptied) |
| **Network** | Other computers on LAN |
| **Folder** | Yellow file holder |
| **File** | Document, picture, etc. |
| **Shortcut** | Arrow on the icon — **pointer**, not the real file |
| **Application** | Word, Chrome, Paint |

**Double-click** an icon to open it (classic). **Single-click** if the folder is set that way.

---

## 2A. Using the mouse and moving icons (official line 2-d)

The syllabus separately asks: *using mouse and moving icons on the screen*.

| Mouse action | What it does |
|--------------|----------------|
| **Point** | Move the pointer onto an icon |
| **Left-click** | Select one icon (it becomes highlighted) |
| **Double-click** | Open the program or folder |
| **Right-click** | Context menu (Open, Delete, Create shortcut…) |
| **Drag and drop** | Hold left button on an icon, move, release — **moves the icon** on the desktop or into a folder |
| **Click empty desktop + drag** | Draw a box; select many icons |
| **Ctrl + click** | Select several icons one by one |
| **Shift + click** | Select a range in a folder |

**Moving icons**

1. Left-click the icon and **keep the button down**.  
2. Drag to a new place on the desktop.  
3. Release.  

Or: right-click desktop → **View → Auto arrange icons** (ON = Windows lines them up; OFF = you can place them freely).  
**Align icons to grid** keeps equal spacing.

**Mouse pointer shapes (MCQ):** arrow (normal), I-beam (text), hourglass / circle (busy), hand (link).

**Left-handed users:** Control Panel → Mouse → switch primary button.

## 3. Parts of a window (must memorise)

```
+--------------------------------------------------+
| Title bar                    [_] [□] [X]         |
| Menu bar   File  Edit  View  ...                 |
| Toolbar    [New] [Open] [Save] ...               |
+--------------------------------------------------+
|                                                  |
|                 Work area                        |
|                                                  |
+--------------------------------------------------+
| Status bar     Page 1    100%                    |
+--------------------------------------------------+
```

| Part | Job |
|------|-----|
| **Title bar** | Name of the file/program; drag to move the window |
| **Menu bar** | Words: File, Edit, View, Insert… Click for a list |
| **Toolbar / Ribbon** | Picture buttons for common jobs |
| **Status bar** | Bottom line — page number, zoom, Caps Lock hints |
| **Scroll bar** | Move up-down or left-right |
| **Work area** | Where you type or draw |

**Taskbar** (usually bottom of the **screen**, not inside one window): Start button, open programs, clock, volume, network.

**System tray / notification area:** clock, speaker, Wi-Fi, battery (right side of taskbar).

## 4. Window settings / Control Panel

**Control Panel** (or **Settings** in Windows 10/11) is where you change the computer’s behaviour.

Classic items the syllabus names:

| Setting | What you do |
|---------|-------------|
| **Date and time** | Clock, time zone (India: IST, UTC+5:30) |
| **Sound** | Speaker volume, sounds for errors / startup |
| **Display / Personalisation** | Wallpaper, resolution, screensaver |
| **Mouse** | Speed, double-click, left/right button (for left-hand users) |
| **Keyboard** | Repeat rate, language |
| **Programs and Features** | Uninstall software |
| **Devices / Printers** | Add printer |
| **Network** | LAN / Wi-Fi |
| **User accounts** | Password, new user |
| **Power** | Sleep, shutdown |

**How to open (typical):** Start → Settings, or search “Control Panel”. Older: Start → Control Panel.

---

## 5. Wallpaper and screensaver

| Item | Meaning |
|------|---------|
| **Wallpaper / desktop background** | Picture behind the icons |
| **Screensaver** | Moving image after the PC is **idle** for some minutes; once used to protect old CRT screens; now also a lock/privacy habit |
| **Theme** | Set of colours, sounds, wallpaper together |
| **Screen resolution** | Sharpness (e.g. 1920×1080) |
| **Sleep / lock** | Windows + L locks the PC |

Right-click desktop → **Personalise** (modern Windows) to change wallpaper.

---

## 6. Using the right button of the mouse

**Right-click** opens a **context menu** — options for **that** object.

Examples:

- Right-click desktop → New folder, Display settings, Personalise  
- Right-click a file → Open, Cut, Copy, Delete, Rename, Properties, Send to, Create shortcut  
- Right-click taskbar → Task Manager (or settings)  

**Left-click** = select. **Double left-click** = open. **Drag** = move.

The syllabus phrase “right bottom of the mouse” means the **right mouse button**.

---

## 7. Creating shortcuts

A **shortcut** is a small link (`.lnk`) with an **arrow**. Deleting the shortcut does **not** delete the real program.

**Ways to create:**

1. Right-click file/program → **Create shortcut** (or Send to → Desktop)  
2. Right-click → **Send to → Desktop (create shortcut)**  
3. Drag with right button → Create shortcuts here  

You can put shortcuts on the **desktop** or **taskbar** (pin) or **Start**.

---

## 8. Basics of Windows setup

When you first start a new PC (or after format):

1. Choose language and country (India)  
2. Connect to Wi-Fi / LAN  
3. Accept licence  
4. Create a **user name and password**  
5. Set date, time, privacy options  
6. Windows Update may run  

**Advancement in Windows** (syllabus word — remember the line of versions):

Windows 95 → 98 → XP → Vista → 7 → 8 / 8.1 → **10** → **11**

Newer ideas: Start menu + search, Settings app, virtual desktops, Microsoft Store, Windows Defender, File Explorer, Cortana/Copilot (name only), touch and pen on some PCs.

**File Explorer** (Windows + E): folders, copy, paste, rename (F2).
