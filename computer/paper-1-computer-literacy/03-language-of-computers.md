# Literacy 3 — Language of Computers

**Syllabus line:** Language of computers  
**Time:** 45 minutes  

---

## Today's goal

1. Binary = language of computers  
2. Bit, nibble, byte, KB, MB, GB, TB  
3. Machine / assembly / high-level language  
4. ASCII one-liners  

---

## 1. Simple explanation

Humans use letters. The computer’s switches are only **ON** or **OFF**. So its language is **binary**: **0** and **1**.

---

## 2. Units (memorise the 1024 chain)

| Unit | Size |
|------|------|
| Bit | 0 or 1 — smallest unit |
| Nibble | 4 bits |
| Byte | 8 bits — one character (approx) |
| KB | 1024 bytes |
| MB | 1024 KB |
| GB | 1024 MB |
| TB | 1024 GB |

**Word:** bits the CPU handles at once (16 / 32 / 64-bit).

---

## 3. Number bases (names only for Paper-I)

| System | Base | Digits |
|--------|------|--------|
| Binary | 2 | 0, 1 |
| Octal | 8 | 0–7 |
| Decimal | 10 | 0–9 |
| Hexadecimal | 16 | 0–9, A–F |

Paper-I rarely asks long conversion. Paper-II does. If asked: `(1010)₂ = 10` in decimal.

---

## 4. Computer languages

| Level | Meaning | Example |
|-------|---------|---------|
| **Machine language** | Only 0 and 1 | 10110000 |
| **Assembly** | Short words (mnemonics) | MOV, ADD |
| **High-level** | Near English | C, Python, Java, BASIC |
| **4GL** | Database style | SQL |

**Translator:** compiler (whole program) or interpreter (line by line).

---

## 5. Character codes

| Code | Point |
|------|-------|
| **ASCII** | Common English character code. `'A' = 65`, `'a' = 97`, `'0' = 48` |
| **Unicode** | World scripts, including Kannada |
| **BCD** | Each decimal digit in 4 bits |

---

## 6. MCQs

**1.** Smallest unit of data:  
a) Byte  b) Bit  c) KB  d) MB  

**2.** 1 byte =  
a) 2 bits  b) 4 bits  c) 8 bits  d) 16 bits  

**3.** 1 KB =  
a) 1000 bytes  b) 1024 bytes  c) 1000 bits  d) 8 MB  

**4.** Language of computers is:  
a) Only Kannada  b) Binary  c) Only English essays  d) Only Morse  

**5.** ASCII of ‘A’ is:  
a) 97  b) 65  c) 48  d) 32  

**6.** Hex digits include:  
a) 0–7 only  b) 0–9 and A–F  c) only A–Z  d) only 0 and 1  

### Answers

1-b, 2-c, 3-b, 4-b, 5-b, 6-b
