## 1. What is an operating system?

> An **operating system (OS)** is system software that acts as an **interface between the user and the hardware**. It manages the CPU, memory, files, and devices.

Without an OS you cannot easily run Word or Chrome.

```
User → Application (Word) → OS → Hardware
```

**Kernel** = core of the OS.  
**Shell** = how you talk to it (icons or commands).

**Examples:** Windows 10/11, Ubuntu, Linux Mint, Red Hat, macOS, Android, iOS, MS-DOS (old).

---

## 2. Functions (write 6)

1. Process / CPU management  
2. Memory management  
3. File management  
4. Device management (drivers)  
5. Security (password, permissions)  
6. User interface (GUI / CLI)  

Also: booting, error messages, networking.

**Booting** = starting the computer and loading the OS into RAM.  
**Cold boot** = from power off. **Warm boot** = restart.

## 3. Types of operating systems

| Type | Meaning | Example |
|------|---------|---------|
| **Single user, single task** | One user, one job | Old **MS-DOS** |
| **Single user, multitask** | One user, many programs | Home **Windows** |
| **Multi-user** | Many users | Linux server, Unix |
| **Multiprogramming** | Many programs in RAM | All modern OS |
| **Time sharing** | CPU in time slices | Multi-user systems |
| **Multiprocessing** | More than one CPU/core | Modern PCs |
| **Real-time (RTOS)** | Strict time limit | Airbag, robots |
| **Network OS** | Serves a network | Windows Server |
| **Distributed** | Many computers as one | Clusters |
| **Embedded / Mobile** | Inside a device / phone | Android, iOS, TV OS |
| **Batch** | Jobs in a batch, no sitting user | Old mainframes |

## 4. Linux — names the syllabus prints

**Linux** is an open-source OS (kernel by **Linus Torvalds**, 1991). A **distribution (distro)** = Linux + tools + desktop.

| Distro | Exam line |
|--------|-----------|
| **Ubuntu** | Popular, easy, Debian-based, used in many schools |
| **Linux Mint** | Easy desktop; also in the official list |
| **Red Hat** (RHEL) | Enterprise Linux; related: Fedora, CentOS |

**Features:** mostly free, open source, multi-user, strong security, case-sensitive file names, terminal (`ls`, `cd`, `pwd`).

---

## 5. Mac OS (Macintosh)

- Made by **Apple** for **Macintosh** computers (iMac, MacBook)  
- Modern name: **macOS** (older papers say Mac OS / Mac OS X)  
- GUI, Unix-based, not Windows  
- Browser often **Safari**; office often iWork or MS Office for Mac  
- File system: APFS / HFS+ (name enough)

---

## 6. GUI vs CLI

| GUI | CLI |
|-----|-----|
| Icons, mouse, windows | Type commands |
| Windows desktop, macOS | CMD, Linux Terminal |
