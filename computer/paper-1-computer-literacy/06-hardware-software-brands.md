# Literacy 6 — Hardware, Software Types, and Brands

**Syllabus line:** Computer hardware and software types and different brands  
**Time:** 55 minutes  

---

## Today's goal

1. Hardware vs software  
2. Input / output / storage / processing  
3. System, application, utility software  
4. Brand names the paper actually asks  

---

## 1. Hardware (you can touch)

> **Hardware:** physical electronic and mechanical parts of a computer.

| Group | Examples |
|-------|----------|
| **Input** | Keyboard, mouse, scanner, mic, webcam, barcode, MICR, OMR |
| **Output** | Monitor, printer, speaker, projector, plotter |
| **Both** | Touch screen, pen drive, headset with mic |
| **Processing** | CPU (Intel, AMD), GPU |
| **Storage** | HDD, SSD, RAM, ROM |
| **Inside box** | Motherboard, SMPS, cabinet, cooling fan |
| **Ports** | USB, HDMI, VGA, Ethernet (RJ-45), audio jack |

**MICR** = bank cheques. **OMR** = bubble sheets. **OCR** = printed text to digital text.

**Printers:** dot matrix (impact), inkjet, laser (toner).

---

## 2. Software (you cannot touch)

> **Software:** programs that tell hardware what to do.

| Type | Job | Examples |
|------|-----|----------|
| **System software** | Runs the machine | Windows, Linux, macOS, drivers, BIOS |
| **Application software** | User’s job | MS Word, Excel, Chrome, Tally, Nudi |
| **Utility** | Maintain the PC | Antivirus, zip, disk cleanup |
| **Firmware** | In ROM/flash | BIOS / UEFI |

**Program** = set of instructions.  
**Package** = ready-made software (MS Office).

**Open source** = source open (Linux, LibreOffice).  
**Proprietary** = licence (Windows, MS Office).  
**Freeware** = free to use. **Shareware** = try then pay.

| **Antivirus** | Norton, McAfee, Quick Heal, K7, Windows Defender |
| **Printer** | HP, Canon, Epson, Brother |
| **PC makers** | Dell, HP, Lenovo, Acer, Apple |
| **Indian supercomputer** | PARAM — **C-DAC** |
| **Kannada** | Nudi, Baraha |

**Microsoft** → Windows + MS Office.  
**Apple** → Macintosh computers + macOS.  
**Linus Torvalds** → Linux kernel (1991).

## 4. Hardware vs software

| Hardware | Software |
|----------|----------|
| Touchable | Instructions |
| Keyboard, RAM | Windows, Word |
| Can break physically | Can have viruses / bugs |
| Needs software to work | Needs hardware to run |

## 5. MCQs

**1.** Which is hardware?  
a) MS Word  b) Linux  c) Scanner  d) Chrome  

**2.** Windows is:  
a) Application  b) System software  c) A printer  d) A port  

**3.** Intel is a brand of:  
a) Paint only  b) Processor  c) Only chairs  d) Only ink  

**4.** MS Office is:  
a) OS  b) Application package  c) A CPU  d) A cable  

**5.** Ubuntu is:  
a) A printer  b) A Linux OS  c) A mouse brand only  d) RAM type  

**6.** MICR is used for:  
a) School OMR only  b) Bank cheques  c) Only games  d) Only music  

**7.** Apple’s desktop OS is:  
a) Android  b) macOS  c) Red Hat only  d) MS-DOS only  

**8.** Laser printer uses:  
a) Ribbon pins  b) Toner  c) Only water  d) Floppy  

### Answers

1-c, 2-b, 3-b, 4-b, 5-b, 6-b, 7-b, 8-b
