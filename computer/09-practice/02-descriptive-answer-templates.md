## Ready cores (expand to 8–12 lines in the hall)

### Computer

A computer is an electronic device that accepts data, processes it, and gives information (IPOS). Characteristics: speed, accuracy, diligence, versatility, storage. Limitation: GIGO, no feelings. Example: school marks list.

### CPU

CPU = ALU + CU + registers. ALU calculates; CU controls; PC/IR/MAR/MDR store addresses and instructions. Fetch–decode–execute. Diagram.

### Memory hierarchy

Registers → cache → RAM → HDD/SSD. Down the pyramid: slower, larger, cheaper. RAM volatile; ROM not.

### OS functions

Interface + manager of process, memory, file, device, security, UI. Examples Windows, Ubuntu.

### Deadlock

Circular wait for resources. Four conditions: mutual exclusion, hold and wait, no preemption, circular wait. Handle: prevent, Banker avoid, detect, or ignore.

### Stack / Queue

LIFO push-pop (undo, back button). FIFO enqueue-dequeue (printer). Diagram.

### OOP

Class blueprint, object instance. Encapsulation, abstraction, inheritance, polymorphism — one school line each.

### Normalization

Remove redundancy. 1NF atomic; 2NF no partial; 3NF no transitive. Student–subject–teacher split.

### SQL

DDL CREATE; DML SELECT/INSERT. Example CREATE student and SELECT marks>60 ORDER BY marks.

### OSI

7 layers All People Seem To Need Data Processing. TCP/IP has 4. TCP reliable; UDP fast.

### Firewall + cyber

CIA. Firewall filters traffic. School: no unknown pendrive, https, no shared OTP, report bullying.

### SDLC

Requirement → design → code → test → deploy → maintain. Waterfall linear; agile sprints.

### Pedagogy

Demo + lab + project + role play. ZPD scaffolding. Inclusive seating and pairs. Evaluate with checklist.

### Lab

UPS, star LAN, pairing chart, stock and fault registers, licensed software, Nudi, shutdown ritual, no food, teacher present.
