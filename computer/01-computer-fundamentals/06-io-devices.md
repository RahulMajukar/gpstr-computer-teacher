## 1. Simple explanation

The CPU only understands electrical signals. Humans understand letters, sound, and pictures.

**Input devices** change human data → machine signals.  
**Output devices** change machine results → human form.

Together they are **I/O devices**. Extra devices hanging off the computer are **peripherals**.

| Device | Captures | School / exam use |
|--------|----------|-------------------|

| **OMR** | Marked bubbles | **GPSTR OMR sheet**, surveys |

**MICR fonts:** E-13B, CMC-7 (sometimes asked).  
**OMR vs OCR:** OMR reads *marks*; OCR reads *characters*.

## 4. Printers (very common)

| Type | How | Quality / cost | Example use |
|------|-----|----------------|-------------|
| **Dot matrix (DMP)** | Pins hit ribbon | Noisy, cheap, carbon copies | Old office forms |
| **Inkjet** | Sprays ink | Good colour, ink costly | Home / school photos |
| **Laser** | Toner + laser + drum | Fast, sharp text | Office circulars |
| **Thermal** | Heat on special paper | Bills | Shop bills |
| **3D printer** | Builds object layer by layer | Models | STEM lab (if available) |
| **Line printer** | Whole line at once | Very old / mainframe | History |

**DPI** = Dots Per Inch (print sharpness).  
**Impact vs non-impact:** DMP is impact (hits paper). Inkjet and laser are non-impact.

## 5. Devices that are both input and output

Pendrive, touch screen, network card, modem, headset with mic, fax (old), hard disk.

---

## 6. Keyboard facts for MCQ

- **QWERTY** layout (named from first six letter keys)  
- Function keys F1–F12  
- **Toggle keys:** Caps Lock, Num Lock, Scroll Lock  
- **Modifier keys:** Ctrl, Alt, Shift  
- **Enter** = new line / accept  
- **Esc** = cancel  
- Multimedia keys on some keyboards  

---

## 7. School teaching tip

Station activity (Class 4–6): five tables — Keyboard, Mouse, Mic, Monitor, Printer. Children walk and say INPUT or OUTPUT.

For **inclusive class:** mention **braille printer**, **screen reader** (NVDA), **large fonts** — this also scores in Paper-I pedagogy.

## Quick revision box

- Input = in; Output = out  
- MICR = cheques; OMR = bubbles; OCR = printed text  
- Impact = DMP; Non-impact = inkjet, laser  
- Plotter = large drawings  
- Pixel, DPI, resolution  
- Touch screen / pendrive = both
